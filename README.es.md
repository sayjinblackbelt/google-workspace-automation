# ⚙️ Automatización con Google Workspace

[🇧🇷 Português](README.md) | [🇺🇸 English](README.en.md) | 🇪🇸 Español

> **Google Forms · Google Sheets · Apps Script · Automatización de Procesos · Indicadores**

Caso técnico reutilizable de automatización que transforma respuestas de formularios en datos validados, registros clasificados, pendientes e indicadores actualizados automáticamente.

## 📌 Sobre el proyecto

Los procesos basados en formularios suelen requerir revisión manual, organización de respuestas y consolidación de información.

Este proyecto demuestra cómo las herramientas nativas de **Google Workspace** pueden integrarse para reducir tareas repetitivas y crear un flujo estructurado entre recopilación, procesamiento, seguimiento y análisis de datos.

El repositorio funciona como un caso técnico reutilizable sin depender de datos reales ni de organizaciones específicas.

## 🎯 Problema

Los flujos manuales pueden exigir:

- revisar respuestas;
- corregir inconsistencias;
- organizar registros;
- identificar pendientes;
- clasificar prioridades;
- actualizar indicadores;
- consolidar información.

Estas tareas consumen tiempo y pueden generar inconsistencias.

## 💡 Solución

```text
Google Forms
      ↓
Google Sheets
      ↓
Apps Script
      ↓
Validación
      ↓
Normalización
      ↓
Clasificación
      ↓
Dashboard
      ↓
Alertas opcionales
```

## ⚙️ Funcionalidades

- recepción de datos mediante formularios;
- validación de campos;
- normalización de registros;
- identificación de pendientes;
- clasificación de riesgo o prioridad;
- indicadores automáticos;
- dashboard en Sheets;
- disparadores después de nuevas respuestas;
- estructura opcional para alertas.

## 🧠 Competencias demostradas

**Procesos:** mapeo de flujos, requisitos, reglas de negocio y mejora de procesos.

**Google Workspace:** Forms, Sheets y Apps Script.

**Automatización:** disparadores, validaciones, normalización, clasificación y alertas.

**Datos:** estructuración, calidad, indicadores y dashboards.
