## Campos

| Campo | Tipo | Obrigatório |
|---|---|---|
| ID | Resposta curta | Sim |
| Categoria | Lista | Sim |
| Status | Lista | Sim |
| Prioridade | Lista | Sim |

- Concluído

### Prioridade

- Baixa

- Alta

Todos os dados utilizados no case devem ser fictícios.
