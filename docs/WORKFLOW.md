# Workflow

## Fluxo operacional

1. Usuário envia um registro pelo formulário.
2. A resposta chega à planilha.
3. O Apps Script valida os campos essenciais.
4. O registro é normalizado.
5. O sistema classifica a situação por status e prioridade.
6. A aba de processamento é atualizada.
7. Os indicadores são recalculados.
8. Alertas podem ser ativados em evolução futura.

## Governança

O fluxo deve separar dados de entrada, dados processados e indicadores. Alterações relevantes no modelo de dados devem ser documentadas.
