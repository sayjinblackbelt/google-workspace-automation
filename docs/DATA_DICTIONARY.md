# Dicionário de Dados

| Campo | Tipo | Finalidade |
|---|---|---|
| timestamp | datetime | Data/hora do registro |
| id | texto | Identificador único |
| nome | texto | Nome demonstrativo |
| categoria | texto | Classificação do registro |
| status | texto | Situação atual |
| prioridade | texto | Prioridade de tratamento |
| descricao | texto | Informações complementares |
| categoria_risco | texto | Classificação calculada |
| pendencia | texto | Indica necessidade de tratamento |

## Nota

Todos os valores utilizados no case são fictícios.
